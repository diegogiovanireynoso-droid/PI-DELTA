# Hackathon NFL Big Data Bowl UNAM

El dashboard muestra el dominio ofensivo del equipo visitante en el 3er cuarto de la temporada 2021 (semanas 1 a 8), medido en yardas por jugada, y cuántos jugadores cambia la defensa local en esas jugadas, siempre con moda, media y mediana por partido y por temporada. Está publicado en GitHub Pages: `https://<usuario>.github.io/<repositorio>/` (reemplaza con el link de tu repositorio). Para correrlo en local, desde la raíz ejecuta `.venv\Scripts\python -m uvicorn backend.main:app --port 8000` y, en otra terminal, `npm install` y `npm run dev` dentro de `dashboard/`; sin backend, el dashboard lee los JSON de `dashboard/public/data/`, que se regeneran con `.venv\Scripts\python -m backend.export_static`. Los supuestos del análisis y la exploración que lo sustenta están en `data/EXPLORACION/README.md`.
